# 🚀 Prompt Engineering Project

## 📌 Project Title
Prompt Playground - Test, Compare & Optimize AI Prompts

## 🎯 Objective
Build a tool that helps prompt engineers test different prompting strategies (zero-shot, few-shot, chain-of-thought) and compare outputs.

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Version Control: Git & GitHub

## ✨ Features
- Prompt input box with character count
- Output display with copy button
- Prompt engineering tips section
- Responsive design

## 📈 Learning Outcomes
- Understood zero-shot vs few-shot prompting
- Implemented prompt testing interface
- Learned GitHub Pages deployment
